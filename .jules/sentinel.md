## 2024-10-30 - SSRF Vulnerability in Registry HTTP Probes
**Vulnerability:** The registry HTTP probe mechanism using `urllib.request` is vulnerable to Server-Side Request Forgery (SSRF) bypasses. Malicious URLs containing obfuscated IP literals with zone identifiers (e.g., `127.0.0.1%en0`) evade the `_is_blocked_host` loopback check but are successfully resolved by `urllib.request` due to how it handles zone IDs.
**Learning:** `ipaddress.ip_address` raises a `ValueError` for IPv4 and IPv6 addresses appended with a network interface zone identifier (like `%en0` or `%lo0`). However, standard library functions like `urllib.request` can often resolve these strings, leading to a bypass of simple IP literal blocklists.
**Prevention:** When validating hostnames parsed from a URL, explicitly strip surrounding IPv6 brackets (`[` and `]`) and remove any network interface zone identifiers (by splitting on `%` and taking the first part) before passing the string to `ipaddress.ip_address` for strict IP literal validation.
