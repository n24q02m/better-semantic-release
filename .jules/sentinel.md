## 2024-10-24 - SSRF Bypass via Obfuscated IPs
**Vulnerability:** The registry probe's HTTP status checker in `_http_status` was vulnerable to Server-Side Request Forgery (SSRF) bypasses using obfuscated IP formats (like decimal `2130706433` or octal `0177.0.0.1`).
**Learning:** `urllib.parse` does not normalize obfuscated IP addresses. Relying on string matching `parsed_url.hostname` against a hardcoded list of loopback strings (e.g., `"127.0.0.1"`, `"localhost"`) fails to block requests when the IP is encoded. The `socket.getaddrinfo` method is required to fully resolve names to IPs, and `ipaddress.ip_address` can robustly identify loopback, link-local, and unspecified addresses across IPv4 and IPv6.
**Prevention:** Always validate resolved IP addresses using `socket.getaddrinfo` and the `ipaddress` module for SSRF protection, rather than string-matching the parsed hostname.
