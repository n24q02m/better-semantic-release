## 2024-05-24 - Pre-compiled Module-Level RegExes
**Learning:** Python re-compiles regex expressions and re-creates dictionaries/lists every time they are defined inside a function scope. In string processing hotspots (like `convert_md_to_rst` and `parse_git_url`), this introduces measurable overhead. The `parse_git_url` function was using `re.compile(pattern)` on every cache miss while rebuilding the list of normalizers. The `convert_md_to_rst` function built a dictionary of regexes and looped over `.values()` on every call.
**Action:** Always hoist static regex compilation (`re.compile`) and associated replacement mappings into module-level tuples/constants. This reduces overhead per call and makes the function body cleaner. Be careful when migrating regexes: ensure the `re` module (or an appropriate alias, but watch out for unbound aliases like `regexp` in `helpers.py` vs `context.py`) is used correctly in the global scope.
